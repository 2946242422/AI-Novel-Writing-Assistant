# AI 实况执行边界

本模块提供自动导演运行阶段和 LLM 生成过程的临时可视化事件，不负责业务结果、任务状态或数据库写入。

- `LlmLiveBroker` 维护短期会话、最新预览和订阅；完成或失败会话保留 10 分钟，便于页面重连。
- `llmLiveSession` 将 Prompt 调用元数据映射为可订阅的任务、小说、章节上下文。
- `runtimeLiveSession` 把自动导演的恢复、节点开始、完成和失败投影为 `mode=runtime` 会话。运行阶段可以在首次模型调用之前出现，也可以在前置门禁失败时独立结束。
- `http/llmLiveRoutes` 仅以 SSE 输出全局或按任务筛选的快照和增量事件；断开浏览器连接只会取消订阅，不能取消服务端生成。

调用方必须由服务端消费模型流并继续执行原有的解析、校验、修复和保存逻辑。模型输出是未校验预览，运行阶段是持久化事件的临时投影；两者都不能代替正式正文、任务终态或数据库事实。
